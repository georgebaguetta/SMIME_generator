How to use

  1. Import the .p12 file into your email client (eM Client, Outlook, Thunderbird, Apple Mail) using the password you set. Keep it secret: it contains your private key.
  2. Send a signed message to your contacts: their client picks up your public certificate and can then send you encrypted mail.
  3. The certificate is self-signed, so recipients will see an untrusted-issuer warning. To remove it, they need to add the .cer file to their trusted certificates manually.
